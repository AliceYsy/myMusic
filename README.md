# 本地音乐 · LocalMusic

使用 SwiftUI 和 AVFoundation 编写的离线 iOS 音乐播放器，支持 iOS 17 及以上，适配 iPhone 和 iPad。无需后端或第三方依赖。

## 运行

1. 使用 Xcode 打开 `LocalMusic.xcodeproj`。
2. 选择 LocalMusic scheme 和 iPhone 模拟器，点击 Run。
3. 真机运行时，在 Signing & Capabilities 中选择你的 Development Team，并修改 Bundle Identifier 为唯一值。
4. 点击「导入歌曲」，通过系统「文件」选择一个或多个音频文件。云盘文件需先下载。

## 功能

- 批量导入系统支持的音频，如 MP3、M4A、WAV、AIFF。
- 导入时读取歌曲标题、艺术家和时长，缺少标签时使用文件名。
- 将音频复制至应用 Documents/Music，并以 JSON 保存音乐库，重启后仍可使用。
- 按歌曲名或艺术家搜索，删除歌曲时确认。
- 播放、暂停、上一首、下一首、进度拖动。
- 顺序循环、单曲循环、随机播放。
- 后台播放、锁屏及控制中心媒体控制。
- 拔出耳机暂停，处理音频中断。

## 手动验收

- 导入两首音频，关闭后重新打开，确认列表仍存在且能够播放。
- 验证搜索、切歌、进度拖动及三种播放模式。
- 锁屏后验证声音继续、锁屏按钮可控制播放。
- 删除当前歌曲，确认播放停止且文件从音乐库移除。
- 导入损坏或不支持的音频，确认错误提示且不留下无效歌曲。

编译验证不等于真机音频验收；后台、耳机和系统中断行为应在真机验证。

## 数据说明

歌曲仅保存在应用本地，不上传服务器。删除应用会删除其音乐库；在应用内删除导入歌曲不会删除导入来源文件。受 DRM 保护的音频不支持导入。当前没有歌单、在线搜索或云同步功能。

## 预置测试乐曲

应用内置三首由程序合成的原创测试乐曲：晨光漫步、夜色微风、轻快旅程，每首 48 秒。首次运行新版本时自动复制到本地音乐库，已有歌曲保留。测试乐曲可正常播放和删除，删除后不会在重启时自动恢复。音频资源位于 LocalMusic/Samples。
